Project Title: Edge-Commerce Analytics: On-Device AI for Resellers
Project By: Jino Sebastian

​1. The Problem
Independent online sellers and digital product resellers frequently rely on expensive cloud-based APIs to track customer trends, manage catalog metadata, and organize product listings. Relying on cloud services creates continuous subscription costs, introduces latency, and raises data privacy concerns when handling customer interactions.

​2. The Solution
This project proposes a completely localized edge-AI analytics engine designed for small digital retailers. By running intelligence locally on the PC, the system analyzes product trends and automates catalog organization directly on-device, requiring zero internet connectivity or recurring cloud fees.

​3. Model Integration (via Qualcomm AI Hub)
​Text Processing: Uses a lightweight open-source language model (such as Llama 3) to classify customer queries and generate standardized product catalog tags.
​Vision Tagging: Integrates a compact open-source vision model to inspect product images and automatically generate descriptive metadata.

​4. The Hardware Advantage
Running continuous local AI workloads quickly drains resources on conventional processors. Snapdragon-powered PCs utilize a dedicated Neural Processing Unit (NPU) engineered specifically for matrix math and low-power AI inference. Deploying these models through the Qualcomm AI Hub allows independent sellers to run private, real-time analytics with low latency and minimal battery consumption.
